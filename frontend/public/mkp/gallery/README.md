# 精选画廊素材目录

社交广场「精选画廊 3D 轮播」的图片与文案，统一在数据文件维护：
**`src/config/gallery.js`**（顶部有维护说明）。

## 你想定期换图时

1. 把新图放进本目录：`01.jpg` `02.jpg` … `08.jpg`（文件名随意，建议按顺序编号）；
2. 打开 `src/config/gallery.js`，把对应条目的 `img` 改成 `/mkp/gallery/01.jpg` 这样的本地路径，
   顺手改掉卡片上的大标题 `t1 / t2` 与小字 `sub`；
3. 保存后浏览器刷新即可（`npm run dev` 会自动热更新）。

## 当前状态说明

- 目前 `img` 用的是项目内已有素材 `public/mkp/wall/`（与桌面端胶片画廊同一批图），
  **全部为本地文件，不依赖外网**；
- 条目数量即轮播卡片数量（当前 8 张），顺序即轮播顺序；
- 某张图缺失/加载失败时，组件会自动降级到 `public/mkp/p*.jpg` 的兜底图，不会破版。
